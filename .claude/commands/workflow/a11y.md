description: Run the accessibility pass (TalkBack + VoiceOver)
---

Telemetry (non-blocking, silent no-op when unconfigured): before step 1 run `bash .claude/scripts/agent-event.sh run-start accessibility-reviewer "a11y"`; as the last action of this command run `bash .claude/scripts/agent-event.sh run-end accessibility-reviewer succeeded` — or `run-end accessibility-reviewer failed` if the phase could not complete.

Precondition: phase is `quality` (runs alongside /workflow:perf).

1. Launch `accessibility-reviewer` (pass env).
2. Verdict from `09-a11y-report.md`:
   - `pass` / `pass-with-tasks` (non-blocking) ⇒ mark a11y clear; both passes clear ⇒ phase → `security`.
   - `fail` ⇒ blocking findings → tasks, phase → `build`, present the checklist.
3. VoiceOver scripts (if macOS unavailable) go to the needs-macOS backlog explicitly — an unverified VoiceOver column blocks a clean release gate until run or waived.
